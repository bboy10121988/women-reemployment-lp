# 婦女再就業自主訓練獎勵說明會

勞動部勞動力發展署「婦女再就業獎勵」自主訓練獎勵的說明會招募頁。純靜態網站，無建置流程，推上 main 分支即由 GitHub Pages 自動更新。

## 檔案

- `index.html` 全部頁面內容
- `styles.css` 樣式，單一主色（深墨綠）與單一圓角尺度
- `script.js` 進場動畫、資格自我檢核、報名表單
- `images/` 圖片，來源 Pexels，可免費商用

## 上線前必須設定

打開 `script.js` 最上方的 `CONFIG`，填入兩個值：

- `ENDPOINT` 報名資料要送去的網址。在 Google 試算表建立 Apps Script 網頁應用程式，部署為「任何人都可存取」，把網址貼進來。
- `LINE_URL` 官方 LINE 加入好友連結。

`ENDPOINT` 留空時，表單會顯示改用 LINE 聯繫的訊息，不會靜靜吃掉報名資料。

## 內容準則

頁面文案刻意避開「免費」「政府出錢」這類講法。實際流程是學員先自行支付課程費用，結訓後才申領獎勵、審核通過才撥款。費用與風險段落與頁尾免責聲明不得移除。

資格與金額依據：[婦女再就業獎勵實施要點](https://laws.mol.gov.tw/FLAW/FLAWDAT0201.aspx?id=FL102139)
